# Архитектура эталонного профиля Ортомедия

**Статус:** зафиксированные решения (согласовано с Yumis)

## Модель данных отзывов

- Одна компания → **единый список всех отзывов**
- `source` является **атрибутом** каждого отзыва (не отдельным разделом/вкладкой отзывов)
- Публично отзывы всегда показываются как единый список (с возможностью фильтрации по source)

## Слои контента

Строгое разделение:

1. **FACT** — оригинальный отзыв (текст, оценка, дата, source, review_id, provenance)
2. **EVIDENCE** — проверяемые доказательства (частоты, supporting_review_ids)
3. **ANALYSIS** — извлечённые темы, тональность, сильные/слабые стороны (наш слой)
4. **AI SUMMARY** — вторичная выжимка, явно помеченная, со ссылками на Evidence

AI Summary никогда не смешивается с оригинальными отзывами и не становится источником истины.

## Рейтинг

- Общий «Рейтинг Отзовика» на первом этапе **не рассчитывается**
- Показываем только матрицу рейтингов по источникам + объём + свежесть
