# ortomediya

Эталонный профиль компании **Ортомедия** для проекта «Отзовик».

**Репозиторий:** рабочее пространство для документации, архитектурных решений и последующей разработки профиля `ortomediya.отзыв.com`.

## Текущий статус

- Этап: проектирование и документация
- Код и дизайн **не** пишутся до отдельного задания
- Все архитектурные решения согласуются с Yumis

## Ключевые принципы (зафиксированы)

- Одна компания → единый список всех отзывов
- Источник является **атрибутом** каждого отзыва, а не отдельным разделом
- Темы и тональность извлекаются из отзывов для слоя Analysis, но публично отзывы остаются единым списком
- AI Summary строго отделён от оригинальных отзывов
- Принцип: **FACT → EVIDENCE → ANALYSIS → AI SUMMARY**
- Общий «Рейтинг Отзовика» на первом этапе **не рассчитывается**
